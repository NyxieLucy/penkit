# over view 
so basically, it's TUI app that gathers most pen testing commands a rookie or advanced user can make (at least the ones i know)
it's rust based, made with Ratatui
it has a lot of modes, like the recon mode the newly added Metasploit sqlmap etc... 
also i tried to not make it crowded, as i said before, only tools i know personally

the app also has doctor command that checks if you own the necessary tools in it

## how to use:
just type :
```
git clone https://github.com/NyxieLucy/penkit
cd penkit
cargo run 
```
of course you can build it, but i'm assuming you'd like to customize it to your liking
